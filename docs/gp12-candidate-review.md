# GP12 重建候选：采用前审阅

版本：`GP12_REBUILD_CANDIDATE_V1`。状态：新编写的研究候选，尚未批准采用；原 `GP_V11` 的三个恢复缺口继续保留。本包不修改原 Formal/OOS 准入代码。

## 这次补齐什么

| 文件 | 用途 |
|---|---|
| `scripts/gp12_candidate_v1.py` | 12因子计算、归一化、分层总分、候选排序、研究仓位与退出条件、历史标签概率映射、包校验入口 |
| `scripts/gp12_eastmoney_adapter_v1.py` | Eastmoney 复权日线、资金流与行情元数据的分段请求/重试/解析适配；对未接通的特征族显式报告缺口 |
| `scripts/test_gp12_eastmoney_adapter_v1.py` | 适配器解析、分段窗口和 fail-closed readiness 测试 |
| `data/GP12_CANDIDATE_PARAMETERS_V1.json` | 明确提出的权重、分数阈值、Top-N、持有期、仓位及成本规则 |
| `data/GP12_CANDIDATE_FACTORS_V1.json` | 固定公式版本、全部因子公式、窗口、单位、数据缺失规则 |

三个文件均可读取和校验，校验报告记录真实内容哈希。这里的“补齐”指新候选的工程实现，不能解释为找回了原模型。

另外，`feature_input_readiness()` 与 `raw_panel_gap_report()` 只做接线诊断：它们会区分“快照结构完整”和“来源已实质验证”，并明确指出现有 RAW 日线字段不能替代复权收盘、换手率、主力净流、市场/板块宽度或 15/60 分钟数据。

Eastmoney 适配器已实测到 `300592.SZ` 的复权日线短区间可返回；长区间及资金流/指数接口会间歇性返回 HTTP 502，适配器已改为最多31个自然日分段、重试、去重合并，并将失败保留为来源缺口，不把一次成功响应升级为完整输入验证。

## 需要采用的具体设计

| 因子 | 候选权重 | 作用 |
|---|---:|---|
| 市场状态 | 8% | 市场5日与20日动量 |
| 市场宽度 | 4% | 最近5日市场广度 |
| 板块相对强弱 | 10% | 板块相对市场的5/10/20日动量 |
| 板块趋势 | 7% | 20日对数价格斜率与拟合程度 |
| 板块宽度 | 8% | 最近5日板块广度 |
| 价格位置 | 12% | 20/60/120日区间位置 |
| 多周期动量 | 10% | 个股5/10/20/60日动量 |
| 趋势质量 | 8% | 60日趋势斜率与拟合程度 |
| 路径效率 | 7% | 20日净位移/绝对波动路径，保留方向 |
| 回撤修复 | 8% | 最近60日高点之后的跌幅修复程度 |
| 量价资金效率 | 10% | 涨幅/换手、资金强度与持续性，并压低孤立资金脉冲影响 |
| 盘中确认 | 8% | 分开读取15分钟与60分钟已收盘数据 |

这些因子名称和权重来自未确认的历史线索，本包把它们作为明确的新提案。精确公式、缩放、买卖阈值和仓位政策均为本次新编写，未宣称用户以前确认过这些具体规则。

所有因子映射到0—100分，总分按权重加总。总分不等于上涨概率；概率仅从已完成且具备时间信息的历史标签估计，样本不足时返回不可用。

候选研究规则：入选分数至少60分，最多10只；个股20日动量必须为正；单股权重上限10%、同板块合计上限20%。退出检查为持有3个市场交易日、较入场价格下跌8%，或评分低于45。每日收盘信号最早在下一市场交易日考虑执行。单边10bp成本只作为待采用的回测输入；本评分器不计算实际成交、实际成本或策略收益。

保持现有流动性约束：20个市场交易日成交额**中位数**至少8,000万元、交易密度至少80%、此前至少120个实际交易日，且当日可交易。原规则将非交易日成交额记为0；本候选要求121个连续且数据完整的市场日，因此会更严格地拒绝有停牌缺口的历史片段。未知ST状态、涨停无法买入、不可交易或关键数据缺失均不形成可执行入选信号。

## 当前数据接入边界

| 数据 | 已核对证据 / 接入要求 |
|---|---|
| RAW日线 | V4.82已验证文件的生成脚本列为 `symbol,date,open,high,low,close,volume,amount,source`；覆盖847只、1,011,607行。 |
| 复权序列 | 项目已有复权审计链；新评分器仍需明确接入审计后的序列，不能直接把RAW收盘当复权收盘。 |
| ST、交易状态、流动性 | 已有独立PIT-ST与流动性产物；需以同日期、同股票和可获知时间绑定。 |
| 指数、行业、板块广度 | 不在上述RAW文件列中。需绑定所用基准、PIT行业成员及其数据来源；847只验证样本不能无说明地代表全市场。 |
| 换手率、主力净流入 | 不在上述RAW文件列中；不能用成交量或成交额替代后声称已取得资金因子。 |
| 15/60分钟数据 | 不在上述日线RAW文件列中；必须是信号时已收盘、已可获知的数据。 |
| 历史标签 | 按官方市场交易日推进T+1/T+2/T+3；目标日停牌/缺失时不跳到下一根个股K线。须单独验证标签数据来源。 |

输入中的来源ID和时间戳可以追踪调用者声明，不能单独证明提供方数据真实。当前代码测试是工程验证，不是这些生产输入全部接通的证明。

## 采用边界

原始策略代码在可访问的历史资产中没有找回。两个早期 `GP_V11_FORMAL_EVIDENCE_PACK_v39.zip`、`v310.zip` 的文件列表也仅含证据采集器、日历与ST审计输入。

因此，需要决定是否把上述**新候选**作为后续研究版本。该决定会改变评分及交易规则，不能当成普通代码修复或原版恢复。即使采用，也须先补齐并审核实际特征输入，冻结这三个文件的哈希，然后另行锁定评价窗口。2026年9月新制定的规则不能自动把2026年4月18日至9月8日的历史窗口宣称为严格未见的OOS。

本候选强制限制在原Formal截止日2026-04-17以内，包校验始终输出：`historical_strategy_recovered=false`、`model_freeze_allowed=false`、`oos_metrics_allowed=false`、`adoption_status=UNAPPROVED`。没有创建原模型冻结文件或运行OOS指标。
